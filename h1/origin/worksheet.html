스펙트럼과 우주의 구성 원소빛으로 읽는 원소의 지문

학번이름
학습 목표스펙트럼의 종류를 구별하고, 별빛의 스펙트럼을 분석하여 우주를 구성하는 원소를 알아낼 수 있음을 설명할 수 있다.통과1 Ⅱ
1개념 정리 · 스펙트럼의 종류
  • 스펙트럼: 빛을 프리즘이나 분광기에 통과시킬 때 파장에 따라 나누어진 색의 띠
  • 연속 스펙트럼: 고온의 고체나 밀도가 큰 기체에서 나오는 빛 → 모든 파장의 빛이 연속적인 색의 띠로 나타남
  • 방출 스펙트럼: 고온의 기체가 방출하는 빛 → 검은 바탕에 특정 위치의 밝은 선
  • 흡수 스펙트럼: 연속 스펙트럼의 빛이 저온의 기체를 통과할 때 → 연속 스펙트럼에 검은 선
  • 같은 원소는 방출선과 흡수선의 위치가 같다. 원소마다 선의 위치가 달라 원소의 지문 역할을 한다.

별 2
4확인 문제

우주의 별빛 스펙트럼에서 가장 강하게 나타나는 원소 두 가지와, 그 의미는?

수소와 헬륨. 우주를 구성하는 원소의 대부분(질량비 약 98 %)이 수소와 헬륨임을 뜻한다.

가로등의 노란빛을 분광기로 보았더니 589 nm 부근에 밝은 선이 나타났다. 가로등에 들어 있는 원소는?

나트륨(나트륨등)
생각 넓히기

천문학자들은 태양 스펙트럼에서 지구에서 알려지지 않았던 선을 발견하고 새 원소의 이름을 붙였다. 이 원소는 무엇이며, 이름은 어떤 뜻일까?

헬륨(He). 그리스어로 태양을 뜻하는 헬리오스(helios)에서 이름을 따왔다. 지구보다 태양에서 먼저 발견된 원소이다.

빅뱅과 원소의 생성우주의 처음 몇 분

학번이름
학습 목표빅뱅 우주론에 따라 우주 초기에 기본 입자, 원자핵, 원자가 만들어지는 과정을 설명하고, 수소와 헬륨의 질량비를 해석할 수 있다.통과1 Ⅱ
1개념 정리 · 빅뱅 우주론
  • 빅뱅 우주론: 약 138억 년 전 매우 뜨겁고 밀도가 큰 한 점에서 대폭발로 우주가 시작되어 팽창하며 식어 왔다는 이론
  • 우주가 팽창하며 온도가 낮아짐 → 기본 입자(쿼크, 전자) → 양성자와 중성자 → 원자핵(빅뱅 후 약 3분) → 원자(약 38만 년)
  • 원자가 만들어지자 빛이 물질에 가로막히지 않고 진행 → 오늘날 우주 배경 복사로 관측된다.
  • 빅뱅 때 만들어진 원소는 주로 수소와 헬륨이다.

빅뱅과 원소의 생성 확인

학번이름
3수소와 헬륨의 질량비 구하기
  • 빅뱅 후 약 3분, 양성자 : 중성자의 개수비는 약 7 : 1이었다.
  • 양성자 14개, 중성자 2개가 있을 때 헬륨 원자핵(양성자 2 + 중성자 2)은 1개 만들어지고, 양성자(수소 원자핵) 12개가 남는다.
  • 질량비 수소 : 헬륨 = 12 : 4 = 3 : 1
관측된 우주의 수소 : 헬륨 질량비(약 3 : 1)는 빅뱅 우주론의 예측과 일치한다.
4확인 문제

빅뱅 우주론을 뒷받침하는 증거 세 가지를 쓰시오.

우주 배경 복사, 수소와 헬륨의 질량비(약 3 : 1), 멀리 있는 은하일수록 빨리 멀어진다(우주 팽창).

원자가 만들어지기 전 우주가 불투명했던 까닭은?

자유롭게 돌아다니는 전자가 빛과 계속 충돌(산란)해 빛이 직진하지 못했기 때문이다.
생각 넓히기

우주 배경 복사는 처음에 약 3000 K의 빛이었지만 지금은 약 2.7 K의 전파(마이크로파)로 관측된다. 그 까닭을 우주 팽창과 연결해 설명해 보자.

우주가 팽창하면서 빛의 파장도 함께 늘어나 에너지가 낮아졌기 때문이다(온도가 낮은 복사처럼 보인다).

별의 진화와 무거운 원소의 생성우리는 별의 먼지

학번이름
학습 목표별의 진화 과정에서 핵융합으로 무거운 원소가 만들어지는 과정을 설명하고, 지구와 생명체를 이루는 원소의 기원을 추론할 수 있다.통과1 Ⅱ
1개념 정리 · 별 내부의 핵융합
  • 별은 중심부에서 가벼운 원자핵이 합쳐져 무거운 원자핵이 되는 핵융합 반응으로 에너지를 낸다.
  • 주계열성: 수소 원자핵 4개 → 헬륨 원자핵 1개 (줄어든 질량이 에너지로 전환)
  • 적색 거성: 헬륨 → 탄소, 산소 / 질량이 매우 큰 별: 탄소 → 네온, 산소 → … → 철까지 생성 (양파 껍질 구조)
  • 철보다 무거운 원소(금, 우라늄 등): 초신성 폭발 같은 극단적인 환경에서 생성

별의 진화와 무거운 원소의 생성 확인

학번이름
3확인 문제

질량이 큰 별에서도 핵융합이 철에서 멈추는 까닭을 핵자당 결합 에너지 그래프로 설명하시오.

철 원자핵은 핵자당 결합 에너지가 가장 커서 가장 안정하다. 철을 융합해도 에너지가 방출되지 않고 오히려 흡수되므로 핵융합이 더 이상 별을 지탱하지 못한다.

지구 생명체의 몸을 이루는 탄소·산소·철의 기원을 우주 역사 순서로 설명하시오.

빅뱅으로 수소·헬륨 생성 → 이전 세대 별 내부 핵융합으로 탄소·산소·철 생성 → 별의 죽음(행성상 성운, 초신성)으로 우주에 방출 → 성운이 수축해 태양계·지구 형성 → 생명체의 재료
생각 넓히기

금(Au)은 지구에서 왜 희귀할까? 원소가 만들어지는 과정과 연결해 생각해 보자.

금은 철보다 무거워 별 내부의 일반적인 핵융합으로는 만들어지지 않고 초신성 폭발이나 중성자별 충돌 같은 드문 사건에서만 만들어지므로 우주 전체에서 양이 매우 적다.
