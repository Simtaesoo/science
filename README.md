# 중학 과학 실험실

2022 개정 교육과정 중학교 과학 단원별 시뮬레이션과 학습지 모음입니다. 빌드 과정 없이 HTML 파일만으로 작동하는 정적 사이트입니다.

## GitHub Pages로 공개하기

1. 저장소 **Settings → Pages**로 이동합니다.
2. **Source**를 `Deploy from a branch`로, **Branch**를 `main` / `(root)`로 고르고 Save를 누릅니다.
3. 1~2분 뒤 `https://<아이디>.github.io/<저장소 이름>/` 주소로 열립니다.

## 폴더 구조

```
index.html            메인 화면 (학년 → 단원 → 자료)
assets/
  catalog.js          전체 목차와 사이트 이름 · 제작자 설정
  site.css            시뮬레이션 공통 디자인
  worksheet.css/js    학습지 공통 디자인 (A4 인쇄, 정답 보기, QR 코드)
g1/state/             1학년 04 물질의 상태 변화 (시뮬레이션 + 학습지)
g1/gas/               1학년 06 기체의 성질 (시뮬레이션 + 학습지)
g3/energy/            3학년 19 운동과 에너지
g3/heredity/          3학년 21 생식과 유전
```

## 자주 바꾸는 곳

- **사이트 이름과 제작자**: `assets/catalog.js` 맨 위의 `name`, `author`
- **새 자료 추가**: 폴더를 만들어 파일을 넣고, `catalog.js`에서 해당 항목에 `href`를 적으면 메인 화면에 바로 열기 링크가 생깁니다.

## 학습지 사용법

- 화면 위 **[정답 보기]**를 누르면 빈칸과 서술형 예시 답이 붉은 글씨로 나타납니다. 정답 보기를 켠 채 인쇄하면 교사용 정답지가 됩니다.
- **[인쇄하기]**는 A4 기준으로 차시당 앞뒤 2쪽씩 나옵니다. 인쇄 설정에서 '배경 그래픽'을 켜 주세요.
- 학습지의 QR 코드는 해당 시뮬레이션 화면으로 바로 연결됩니다 (사이트를 공개한 뒤에 작동).
