2022 개정 교육과정 중학교 과학과 고등학교 통합과학·물리 단원별 시뮬레이션, 실험·게임, 학습지, 퀴즈, 수업 도구 모음입니다. 빌드 과정 없이 HTML 파일만으로 작동하는 정적 사이트입니다.

주소: https://science.sts0614.workers.dev/

## 앱으로 설치하기

이 사이트는 설치형 웹앱(PWA)입니다. 휴대폰·태블릿·PC에서 메인 화면을 연 뒤 설치하면 아이콘으로 실행되고, 한 번 열어 본 자료는 인터넷이 끊겨도 열립니다.

- 안드로이드(크롬): 메뉴 ⋮ → **앱 설치** 또는 **홈 화면에 추가**
- 아이폰·아이패드(사파리): 공유 버튼 → **홈 화면에 추가**
- PC(크롬·엣지): 주소창 오른쪽의 설치 아이콘

인터넷이 연결되어 있으면 항상 최신 파일을 받으므로, 저장소에 자료를 올리면 설치한 앱에도 그대로 반영됩니다. 관련 파일: `manifest.webmanifest`, `sw.js`, `icons/`

## 교사 잠금

Cloudflare Workers에서 작동합니다(`worker.js`, 설정은 `wrangler.jsonc`). GitHub에 올리면 Cloudflare가 자동으로 다시 배포합니다. 로그인하지 않은 학생에게는 서버가 아래 내용을 지운 뒤 페이지를 보내므로, 페이지 소스를 열어도 보이지 않습니다.

- 학습지 빈칸 정답, 정답 문장·그래프, '정답 보기' 버튼
- 수업 슬라이드 전체(`slides*.html`, 학생이 열면 교사 로그인 화면으로 이동)
- 퀴즈의 '골든벨(교사 진행)' 모드 (학생은 개인 풀이만)
- 수업 진행 도구(`tools/class.html`) 전체

**비밀번호 설정**: Cloudflare 대시보드 → Workers & Pages → science → Settings → **Build** → Variables and secrets → `TEACHER_PASSWORD`를 Secret으로 추가하고 다시 배포(Deployments에서 Retry 또는 GitHub에 아무 커밋). 배포할 때 `build-teacher.mjs`가 비밀번호 대신 확인용 지문만 만들어 씁니다. 비밀번호는 저장소에 적지 않습니다. 바꾸면 기존 교사 로그인이 모두 풀립니다.

**로그인**: 메인 화면 오른쪽 위 '교사 로그인' 또는 `/teacher`. 한 번 로그인하면 그 기기에서 30일 동안 유지되고, 페이지 아래 '교사 모드 끝내기'로 나갈 수 있습니다.

## 폴더 구조

```
index.html              메인 화면 (학교급·과목 → 단원 → 자료)
assets/
  catalog.js            전체 목차와 사이트 이름 · 제작자 설정
  simkit.js, site.css   시뮬레이션 공통 도구와 디자인
  app.js, app.css       실험·게임 앱 공통 틀
  worksheet.css/js      학습지 공통 디자인 (A4 인쇄, 정답 보기, QR 코드, 그래프 칸)
  quizbank.js           중학교 퀴즈 문항,  quizbank-hs.js 고등학교 퀴즈 문항
<단원 폴더>/sim.html     차시별 시뮬레이션 (주소 끝 #차시이름으로 바로 열림)
<단원 폴더>/worksheet.html  학습지
```

## 자주 바꾸는 곳

- **사이트 이름과 제작자**: `assets/catalog.js` 맨 위의 `name`, `author`
- **새 자료 추가**: 폴더를 만들어 파일을 넣고, `catalog.js`의 해당 단원 `items`에 `{kind, title, href}`를 적으면 메인 화면에 링크가 생깁니다. `kind`: `sim` 시뮬레이션, `app` 실험·게임, `quiz` 퀴즈, `ws` 학습지
- **퀴즈 문항**: `quizbank.js` / `quizbank-hs.js`에 `[문제, [보기…], 정답 번호, 해설]` 형식으로 추가 (보기는 화면에서 섞여 나옵니다)

## 학습지 사용법

- 화면 위 **[정답 보기]**를 누르면 빈칸과 서술형 예시 답이 붉은 글씨로 나타납니다. 정답 보기를 켠 채 인쇄하면 교사용 정답지가 됩니다.
- **[인쇄하기]**는 A4 기준입니다. 인쇄 설정에서 '배경 그래픽'을 켜 주세요.
- 학습지의 QR 코드는 해당 시뮬레이션 차시 화면으로 바로 연결됩니다.
